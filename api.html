API

suave.mavros_position_controller

MAVROS local-position state and setpoint publishing helpers.

suave.action_server_utils

Shared helpers for lifecycle-node action servers.

suave.follow_pipeline_lc

Lifecycle node that follows a detected pipeline.

suave.pipeline_detection

Detect an underwater pipeline and provide an ordered inspection path.

suave.pipeline_detection_wv

Detect pipelines while accounting for observed water visibility.

suave.recover_thrusters_lc

Lifecycle node that recovers disabled thrusters.

suave.recharge_battery_lc

Navigate to the recharge station and trigger battery recharging.

suave.ros_service_utils

Shared ROS service-call helpers.

suave.spiral_search_lc

Lifecycle node that commands the vehicle along an expanding spiral.

suave.task_bridge

Provide the common ROS task-to-function bridge implementation.

suave.task_bridge_none

Bridge mission tasks directly to system-mode changes.

suave_monitor.thruster_monitor

Schedule thruster failures and recoveries and publish diagnostics.

suave_monitor.battery_monitor

Simulate and publish the vehicle battery quality attribute.

suave_monitor.water_visibility_observer

Publish a time-varying water-visibility quality attribute.

suave_metrics.mission_metrics

module used to save metrics.

suave_runner.suave_runner

Run repeatable SUAVE experiment campaigns and collect their results.

suave_runner.statistical_analysis

Compare SUAVE experiment metrics using nonparametric statistics.
