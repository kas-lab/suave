# SUAVE Missions

This package contains SUAVE mission nodes, launch files, and configuration.

The following files contain the configurations used for experiments performed
for the PLANTA paper, which is still unpublished:

- `config/planta_exp1_mission_config.yaml`
- `config/planta_exp2_mission_config.yaml`
- `config/planta_exp3_mission_config.yaml`
