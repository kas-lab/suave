# SUAVE Missions

This package contains SUAVE mission nodes, launch files, and configuration.

The following files contain the mission configurations used by the
`exp1`-`exp3` experiment campaigns (see `suave_runner/config/runner/`).
Their `planta_` prefix is a holdover from the paper these campaigns were
first written for -- a comparative study of several managing systems,
including this repo's own `bt`, `metacontrol`, `random`, and `none`:

- `config/planta_exp1_mission_config.yaml`
- `config/planta_exp2_mission_config.yaml`
- `config/planta_exp3_mission_config.yaml`
